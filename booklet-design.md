# Fifteen25 Booklet Design (Magazine-Style Vision Pack)

## 1) Rule of the Booklet

### Brand architecture
- **15–25 Window = design language**
  - Use visual-first system: icons, charts, ladders, cycles, tiles, timeline overlays, and minimal layouts.
- **Fifteen25 = content story**
  - Narrative sequence: **Where → There** + **Four Windows** + **TBIP** + **(Re)Sponse** + **There outcomes**.

### Magazine style (minimal)
Each spread follows one core idea only:
- **Left page = Vision narrative** (WHY / WHAT)
- **Right page = Framework visual** + one short “How to use” line
- Keep it concise and editorial (vision share), not curriculum teaching.

## 4) Minimal Page Recipe (apply to every spread)

### Left page (Vision)
- Title (5–7 words)
- 2 short anchoring lines
- 90–120 words editorial paragraph
- 1 pull quote

### Right page (Visual)
- One hero framework visual from 15–25 icon system
- 4–6 bullets only
- One line: “Use it like this” (not a checklist)

This keeps the booklet as a vision document with repeatable rhythm and high scanability.

---

## 5) Compression Plan (if reduced to 24–28 pages)

To create a tighter edition:
- Combine window spreads:
  - 11+12 (Transitions)
  - 13+14 (Choices + Stewardship)
  - 15+16 (Challenges + Opportunities)
- Keep TBIP as 5 spreads:
  - overview + 4 pillars
- Keep (Re)Sponse as 5 spreads:
  - overview + 4 grouped stage pairs
- Keep There outcomes as 2 spreads:
  - 4F + 4L
- Move scriptures to back cover panel only.

---

## 6) Production Specs

- **Trim:** A5 portrait (148 × 210 mm)
- **Bleed:** 3 mm all sides
- **Margins (safe):** 10–12 mm for body content
- **Color mode:** CMYK for print
- **Raster assets:** 300 DPI minimum
- **Output files:**
  - PDF/X-1a (print)
  - compressed PDF (digital share)
- **Paper suggestion:**
  - Cover: 170 gsm silk
  - Inside: 120 gsm uncoated
